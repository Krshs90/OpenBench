# Security Policy

## Supported Versions
Only the latest version of OpenBench receives security updates.

| Version | Supported          |
| ------- | ------------------ |
| v1.0.x  | :white_check_mark: |

## Reporting a Vulnerability

If you discover a security vulnerability within OpenBench, please DO NOT open a public issue.
Instead, send an e-mail to Krish Shah at Krshs90@gmail.com. All security vulnerabilities will be promptly addressed.
